# FitnessApp - Feature Suggestions & Enhancements

**Application:** FitnessApp (Fitness & Wellness Mobile App)  
**Date:** August 3, 2026  
**Module Focus:** Fasting & Islamic Wellness Tools  

---

## Feature Enhancements & Backlog Suggestions

| Suggestion ID | Feature / Module | Enhancement Description | Priority | Target UX Impact |
| :--- | :--- | :--- | :--- | :--- |
| **SUGG-01** | Fasting Tracker | **Auto-Fill Islamic Fasting Window:** Provide a quick-action button in the entry modal (*"Set to Today's Fast"*) that automatically populates `Start Time = Fajr` (Suhoor cut-off) and `End Time = Maghrib` (Iftar) using the user's localized prayer calculations. | **High** | Reduces user input friction by eliminating standard 12-hour clock pickers for daily Islamic fasts. |
| **SUGG-02** | Community Feed | **Enforce Character & Truncation Rules (Posts & Comments):** Implement standard character limits and truncation thresholds. Posts should truncate after **280–300 characters (or ~3–4 lines)** with a `See More` toggle, enforcing a hard post limit of **2,000–3,000 characters**. Comments should truncate after **150–200 characters (or ~2 lines)** with a hard limit of **500–1,000 characters**. | **High** | Keeps the feed scannable, prevents single posts/comments from dominating viewport height, and improves overall scroll performance. |
